# Cycle Compass (add-on folder)

Drop this whole `cycle-compass` folder into the ROOT of the options-scanner repo,
next to the `futures` folder. Commit and push.

Link: https://tealemarlin11.github.io/options-scanner/cycle-compass/

No workflow changes needed. The page fetches the live price and monthly closes
from Coinbase in the browser. data/prices.json is only a fallback (edit by hand if you like).
Edit the cycle assumptions in the DEF block near the top of index.html.
